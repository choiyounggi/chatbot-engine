# HTTP API 지연 (Phase 5)

`uv run python bench/api_latency.py`가 생성한 파일이다. 손으로 고치지 말 것.

- 환경: arm64 macOS 26.1, Python 3.14.4. 실제 서버(uvicorn)에 HTTP로 요청했다. NLU 모델은 MPS에서 단일 워커 + 대기 0ms 배칭으로 돌렸다.
- 날씨 액션은 가짜 네트워크를 쓴다(엔진과 NLU만 잰다). 실제 Open-Meteo 호출은 네트워크 시간이 더해진다.
- 기준: 두 경우 모두 p95 ≤ 50ms (계획 Phase 5, 2026-11-09 합의)
- GPU 깨워 두기: 쉬는 동안 20ms마다 모델을 한 번 호출한다(`make serve KEEP_WARM_MS=...`). GPU를 계속 쓴다.
- 판정: 기본 설정 통과, GPU 깨워 두기 통과. p95는 요청 40개 중 두 번째로 느린 값 근처라 실행마다 수 ms씩 흔들린다.

| 경우 | 요청 수 | p50 ms | p95 ms | 최대 ms | 기준 |
|---|---|---|---|---|---|
| 유휴 후 단일 요청 (0.5초 간격), GPU 깨워 두기 끔 (기본) | 40 | 27.1 | 48.8 | 68.9 | ✅ |
| 동시 4개 세션, GPU 깨워 두기 끔 (기본) | 160 | 31.5 | 40.0 | 106.3 | ✅ |
| 유휴 후 단일 요청 (0.5초 간격), GPU 깨워 두기 20ms | 40 | 21.8 | 38.1 | 47.8 | ✅ |
| 동시 4개 세션, GPU 깨워 두기 20ms | 160 | 31.0 | 36.2 | 63.5 | ✅ |
