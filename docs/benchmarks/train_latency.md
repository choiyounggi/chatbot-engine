# 학습 중 대화 지연 (빌더 계획 E-A)

`uv run python bench/train_latency.py`가 생성한 파일이다. 손으로 고치지 말 것.

- 환경: arm64 macOS 26.1, Python 3.14.4. 실제 서버(uvicorn)에 HTTP로 동시 4세션이 쉬지 않고 대화한다. NLU 모델은 MPS 단일 워커.
- 학습: 빌더 API `POST /versions`(배포용 학습: 교차검증 + 적합)가 끝날 때까지 잰다. 날씨 액션은 가짜 네트워크.
- 기준: 학습 중 동시 4세션 p95 ≤ 50ms (엔진 지연 기준과 같음).
- 판정: 통과 (학습 전용 줄 p95 46.6ms).

| 경우 | 요청 수 | p50 ms | p95 ms | 최대 ms | 학습 시간 |
|---|---|---|---|---|---|
| 학습 없음 (기준) | 240 | 31.3 | 34.5 | 50.6 | - |
| 학습 중, 같은 줄 (E-A 전: 먼저 온 순서) | 167 | 34.3 | 760.6 | 2229.0 | 7.3초 |
| 학습 중, 학습 전용 줄 (E-A: 번갈아 처리, 학습 묶음 4) | 3919 | 40.1 | 46.6 | 189.5 | 26.2초 |
