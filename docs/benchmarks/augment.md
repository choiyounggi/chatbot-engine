# LLM 예문·비슷한 질문 채우기 측정 (E-H)

`uv run python bench/augment_eval.py`가 만든 파일. 손으로 고치지 말 것.

- 블록마다 20개·FAQ마다 10개를 제안받아(오타는 따로 한 번, 나머지 종류는 한 번) 엔진이 거른 뒤 `ok`를 모두 넣음(사람이 전부 받아들인 경우).
- 오타판: 문장마다 규칙으로 오타 하나(LLM과 다른 방식). 종류별 문장 수 final 79, space 74, tense 33, vowel 39, yo 10.
- 칸: 값 (원래와의 차이 [같은 문장끼리 쌍 부트스트랩 95% 구간]). 블록은 배포 학습 후 실제 해석기, 지식베이스는 `Knowledge.consult`(재순위 판단, 블록 판단은 양쪽 다 원래 모델).
