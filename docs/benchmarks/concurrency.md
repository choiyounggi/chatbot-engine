# 임베딩 동시 요청 측정

`uv run python bench/concurrency.py`가 생성한 파일이다. 손으로 고치지 말 것.

- 모델 `dragonkue/snowflake-arctic-embed-l-v2.0-ko` (mps float16), torch 2.15.0. 임베딩만 잰 값이다(분류기 연산 < 1ms 별도).
- 수준마다 요청 240개. 모든 모델 호출은 워커 스레드 하나에서 실행한다. 측정 전 배치 크기 1~16을 한 번씩 실행해 MPS 첫 실행 지연을 뺐다.

## 유휴 후 단일 요청 — 채팅 사용자처럼 요청 사이에 쉬는 경우

요청 30개를 하나씩, 매번 정해진 시간만큼 쉰 뒤 보냈다. 맥은 쉬는 동안 GPU·CPU 클럭을 내리므로 연속 요청보다 느리다. 실제 채팅의 단일 요청 지연은 이 표가 가깝다.

| 쉬는 시간 | p50 ms | p95 ms |
|---|---|---|
| 0ms | 10.9 | 12.2 |
| 200ms | 19.7 | 25.3 |
| 1000ms | 20.6 | 43.1 |
