# Phase 0 — NLU 베이스라인 결과

`uv run python bench/phase0.py`가 생성한 파일이다. 손으로 고치지 말 것.

- 환경: Apple M4 Pro (arm64), Darwin 26.1, Python 3.14.4, scikit-learn 1.9.1, kiwipiepy 0.24.1, torch 2.15.0, sentence-transformers 6.2.0
- 데이터: 의도 10개(범위 밖 포함), 템플릿 736개 → 거의 같은 템플릿끼리 묶어 497묶음(글자 n-gram 유사도 ≥ 0.75 또는 `arctic` 임베딩 complete-link ≥ 0.9), 지역 표기 193개
- 처음 보는 범위 밖 평가 문장 100개. 그중 2개는 학습용 범위 밖 문장과 `arctic` 유사도 ≥ 0.7이라 '먼 문장만' 열에서 뺐다.
- 교차검증: 묶음 단위 5-fold StratifiedGroupKFold × 시드 5개. 평가 문장은 템플릿의 `{location}`에 무작위 지역을 넣은 것.
- 범위 밖 규칙(모든 조합 동일): `out_of_scope` 클래스가 1위이거나, 1위 확률 < 확률 임계값이거나, 범위 안 학습 문장과의 최대 코사인 < 유사도 임계값이면 거절. 유사도 공간은 임베딩 조합은 임베딩, n-gram 조합은 TF-IDF.
- 임계값: 교차검증 예측에서 범위 밖 재현율 ≥ 0.8를 만족하는 쌍 중 macro-F1 최대(없으면 ⚠). **표의 macro-F1은 교차 적합 값**이다. 템플릿 묶음을 둘로 나눠 한쪽에서 고른 임계값으로 다른 쪽을 쟀다. 표의 임계값은 전체 예측으로 고른 배포용 초기값이다.
- 처음 보는 범위 밖 문장은 임계값 선택에는 쓰지 않는다. 다만 통과 판정에는 쓰므로 95% 신뢰구간(Wilson)을 함께 적는다.
- 기준: macro-F1 ≥ 0.9, 처음 보는 범위 밖 거절률 ≥ 0.8, 추론 p95 ≤ 20.0ms(3회 측정 중 최악값), 학습(임베딩 포함, 모델 로드 제외) ≤ 10.0초
- Kiwi: 모델 로드 0.39초, 단일 스레드 3,381문장/초
- 임베딩 모델:
  - `e5s` = intfloat/multilingual-e5-small (cpu float32, 프롬프트 `'query: '`, 로드 2.5초)
  - `e5b` = intfloat/multilingual-e5-base (mps float16, 프롬프트 `'query: '`, 로드 3.4초)
  - `arctic` = dragonkue/snowflake-arctic-embed-l-v2.0-ko (mps float16, 프롬프트 `'query: '`, 로드 3.3초)
  - `qwen3` = Qwen/Qwen3-Embedding-0.6B (mps float16, 프롬프트 `'Instruct: Classify the intent of a Korean chatbot user message\nQuery:'`, 로드 3.8초)

## 알려진 한계

- 평가 문장은 템플릿에 지역을 무작위로 넣어 만들기 때문에 조사가 어색한 문장(예: "화성시이")이 섞인다.
- 거의 같은 템플릿만 같은 묶음으로 묶는다. "뭐 할 수 있어?"와 "할 줄 아는 게 뭐야" 같은 말바꿈은 학습과 평가에 나뉘어 들어간다. 실제 사용자 입력도 빌더가 쓴 예문의 말바꿈이라는 가정이다.
- 묶음과 '먼 문장' 판정에 `arctic` 임베딩을 쓰므로, 같은 모델 조합에는 오히려 불리하게(보수적으로) 작용한다.
- 조합 40개 중 최고값을 고르므로 선택 편향이 남는다. 위 bootstrap 구간으로 차이가 우연인지 판단할 것.
- 지연은 단일 요청 기준이다. 동시 요청 지연은 Phase 5에서 잰다.
- `delex`는 지역명과 같은 일반 명사("경기", "화성")도 바꾼다. 엔진에서는 Phase 3의 '필요한 엔티티만 채택' 규칙으로 처리한다.
- 정확히 일치하는 예문을 먼저 처리하는 규칙은 이 수치에 반영되지 않는다.
- 처음 보는 범위 밖 문장 100개와 잡담 의도 보강 예문은 이 프로젝트를 위해 새로 쓴 문장이다. 실제 사용자 분포와 다를 수 있다.
