# 봇의 낱말로 오타 고치기 측정 (E-I)

`uv run python bench/spelling_eval.py`가 만든 파일. 손으로 고치지 말 것.

- 경로: 배포 학습한 샘플 봇 모델 + 해석기에 고치기를 넣고 뺌(새 세션마다 한 문장). 지식베이스도 같은 해석기(블록 판단 → `Knowledge.consult`).

- 블록 문장 수: 원문 235, 규칙 오타 235, 자연 오타 148; 지식베이스: 원문 237, 규칙 오타 237, 자연 오타 160.
- 칸: 값 (끔과의 차이 [같은 문장끼리 쌍 부트스트랩 95% 구간]).
